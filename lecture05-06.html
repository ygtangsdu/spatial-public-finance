SPATIAL PUBLIC FINANCE · 第 5–6 讲（模块三 · 城市内空间财政学）

公共服务的资本化 & 财税制度与城市空间结构

第 5 讲 城市内空间财政学 1：城市公共服务的资本化（学校、地铁等）

主线：资本化是空间财政学的显微镜——把看不见的公共服务转译成看得见的房价，但读数之前必须先校准镜头（识别）与理解光学原理（均衡）。本讲是第 7 讲城市内 QSE 的简约式地基。

学习目标
  1. 推导资本化的均衡决定式：供给弹性与迁移摩擦如何共同决定资本化率；
  2. 比较四代识别策略的假设强度与偏差方向；
  3. 掌握 Black (1999) 边界断点设计的细节、贡献与局限；
  4. 综合中国学区房、地铁、房产税试点三大场景的证据；
  5. 运用资本化证据做受益定价与归宿核算；
  6. 评价增值捕获（value capture）作为基建融资工具的论证。

5.1 理论层：资本化由什么决定

从 Oates (1969) 的原始回归（税率负、支出正的联合检验）到现代均衡理论：资本化研究 = 识别（剔除混杂）+ 均衡理论（解释系数大小）。核心决定式：

（5.1）　Δln P ≈ [需求位移] × 1/(1 + η·需求弹性)

η→0（供给受约束）：完全资本化——价格通道、incumbent 房主受益；η→∞：资本化趋零——数量通道、边际入住者受益。结构性结论：资本化率不是"Tiebout 是否存在"的检验，而是住房供给体制的显影。中国学区溢价陡峭的三重放大器：供给约束 + 分选弹性 + 无持有成本。税收与服务资本化对称：房产税开征的净效应 = −税负现值 + 服务增值现值——取决于税收用途（沪渝试点检验此逻辑）。

概念辨析 BOX 5.1｜资本化的三个易混口径
①边际资本化（政策评估对象）：边际变化的房价反应；②总资本化水平（归宿核算对象）：存量差异的全部折现（学区总溢价）；③资本化率（结构参数）：每单位财政流量的价格系数。三者答案与用途都不同，读文献先问"是哪一个"。

5.2 识别层：四代识别策略

代际设计关键贡献 / 威胁
一代 横截面房价对税率/支出回归奠定事实；遗漏变量与分选内生严重
二代 边界断点Black (1999)：学区边界两侧可比住房剥离邻域混杂；构成仍内生、裸分混杂同伴效应、多重断点
三代 政策冲击 DID多校划片、学校新建等自然实验时点清晰；预期效应、规避搬迁、溢出威胁
四代 租金通道租金 vs 房价双通道校验租金无转售预期污染——"干净读数"

Black (1999) 发现学校质量 1 SD 的边界资本化显著但远小于横截面估计——识别越严效应越小。地铁识别要点：处理强度连续化（到站距离）、三时点分解（公布/开工/开通——相当增值在公布期实现）、环带溢出设计、异质性（连 CBD 线路效应远大）。

5.3–5.4 证据层：三大中国场景 + 国际校准

场景识别设计方向量级归宿

多校划片 = 对学区溢价的"贴现率冲击"：确定性变抽签 → 溢价收缩；效应异质（优质学区贬值、薄弱升值 = 再分配）；规避行为侵蚀效果（SUTVA 城市内版本）。沪渝试点的启示：低强度 + 高预期敏感的政策，资本化由预期折现率主导——正好验证式 (5.2) 两期结构。

5.5 政策层：受益定价、归宿核算与增值捕获

归宿链条：服务改善 → 房价上升 → 收益归于政策时点房主；后来者溢价入场 = 预付服务流。"给学校的钱部分变成给房东的钱"——公办投入均等化经资本化部分变成对存量房主的财富转移。

捕获工具机制中国实践评价
房产税存量年度捕获沪渝试点（弱）最稳但政治阻力大
土地增值税交易时捕获存在但征管弱交易触发、漏损大
土地出让金一级市场捕获主体工具一次性预收、激励扭曲
TIF 税收增量融资指定区域增量自偿城投近似物需可信增量核算
联合开发（地铁上盖）实物捕获港铁模式推广最直接、依赖开发权配置

资本化自增强循环的两面：良性（受益融资自我实现）与恶性（服务财富门槛化 + 依赖房价上行预期）。政策边界画在"让循环为服务融资"与"不让服务成为财富特权"之间。

中国实践 BOX 5.2｜教师轮岗与多校划片的评估框架
①政策改变"确定性"→ 溢价应收缩；②效应异质（优质贬、薄弱升 = 再分配，可检验）；③规避侵蚀（搬迁或私立教育 = SUTVA 违背）；④归宿（损失归存量房主 → 政治阻力来源）。把本讲全部工具装配在一个现实政策上——期末论文样板题。

第 6 讲 城市内空间财政学 2：财税制度与城市空间结构（横向蔓延与纵向增长）

主线：城市形态是财政制度的投影——一次性预收的土地出让金造出横向蔓延的城市，年度性的财产税本会造出更紧凑的城。财产税归宿三观点（第 2 讲）在此获得空间形态维度的检验场。

学习目标
  1. 推导 AMM 中城市边界与建筑高度的联立决定与"蔓延 vs 加密"的边际条件；
  2. 解释 Brueckner 蔓延理论中房产税进入蔓延决策的机制；
  3. 掌握土地财政塑造形态的机制链：一次性预收、增量偏好、双轨出让；
  4. 评价中国证据（门限效应、撤县设区）与国际证据；
  5. 设计存量财政转型的政策组合并预测其形态后果。

6.1 理论层：AMM 中的横向与纵向

三重边界联立：横向边界（城市地价 = 农地价 + 转换成本）、纵向边界（边际楼层租金 = 边际建安成本 + 容积率规制影子价格）、再开发边界（拆除重建期权）。分流命题：需求冲击在"边界外推 vs 密度上升"间的分配，取决于横向供给（指标、地形）与纵向供给（容积率、技术）的相对弹性——限制蔓延若不同时放松纵向供给，只会推高房价（Hsieh–Moretti 机制的城市内版本）。

Brueckner 蔓延理论：三个驱动力——交通成本定价不足、开放空间价值低估、房产税对住房消费的扭曲。Brueckner–Kim (2003) 展示房产税对净蔓延的方向依模型设定而变——形态效应的符号是参数问题而非直觉问题，所以需要量化工具。

财政工具捕获时点横向激励纵向激励征管成本
土地出让金一次性（开发时）强扩张中性偏弱低
房产税（存量）年度约束鼓励高
土地增值税交易时弱约束弱鼓励中
开发影响费开发时约束中性中
容积率管制 / UGB行政直接约束直接控制低（影子价格高）
概念辨析 BOX 6.1｜"土地财政"的准确含义
三层常被混用：①狭义——出让金收入；②中义——土地相关全口径收入（出让金+税费+抵押融资）；③激励义——"以土地为杠杆组织增长与财政的体制"。本课程用第③义：关键不是收入规模，而是边际激励结构（一次性预收 + 招商竞争 → 增量偏好）。转型讨论针对边际激励而非存量规模。

6.2 机制层：土地财政的中国机制链

出让金 = 一次性预收的资本化变现（承接第 5 讲式 5.2 对称性）。三个激励后果：收入时间错配（当代花未来的钱）、存量漠视（已售地块无年度回报 → 重增量轻存量）、周期放大（地价顺周期 → 财政顺周期）。

双轨出让的空间后果三联：①工业用地真实价格低于社会机会成本 → 开发区巨型化、低密度（蔓延的产业版，连接 Lu–Wang–Zhu）；②商住用地供给策略性配给 → 大城市房价高企、劳动力流入受阻（Hsieh–Moretti 中国移植的实证基础）；③低价工业区与高价居住区割裂 → 职住分离（AMM 梯度的财政扭曲版）。

门限证据：土地财政对建成区扩张的效应随人口密度上升而增强（仝德等）——密度高 = 变现能力强 = 增量激励放大。识别警示：密度与扩张可能同受增长预期驱动，门限是机制一致性证据而非严格因果。撤县设区：辖区扩大 = 出让权与指标扩大；NSD 系列发现撤并后出让规模与依赖度上升而密度改善有限——"规模上了、密度没上"。反向政策（县改市/省直管县）构成识别冲击（论文题源）。

6.3 证据层：中英文对照

中国证据图谱：扩张效应显著（FE+门限，因果中等）、撤县设区 DID 较强、指标—人口错配机制清晰但量级有争议、开发区形态效应较强、棚改/旧改纵向再开发中等。国际对照三大发现：①影响费 → 边界收缩密度略升；②高财产税州更紧凑（因果弱）；③Prop 13 挤压效应——限制财产税 → 加州转向开发收费 + 严格管制保税基："堵住一种捕获，政府发明更扭曲的替代"。对中国的预测：土地财政退坡若不配套新税基，将出现罚没、收费、隐性债务等替代——第 12、13 讲伏笔。蔓延的财政成本：基建人均成本、服务规模经济损失、通勤与排放、农地生态损失——在规划人口未兑现（新城空置）时显性化。

6.4 政策层：从增量财政到存量财政的转型

三条压力线：边际递减（可售地收缩）、激励矫正（增量偏好 vs 精细治理不兼容）、均等化要求（土地财政归宿偏向有土城市与先入房主）。转型组合表：

选项捕获逻辑横向纵向难点
房产税扩围年度持有约束鼓励评估、政治、沪渝经验放大
土增税强化交易增值中性中性征管博弈、抑制交易
税制整体设计（税基+税率+用途绑定）组合约束鼓励收益观落地
指标跨区交易指标价格化约束鼓励与规划体制兼容
都市圈土地统筹区域捕获约束鼓励第 9 讲治理前提

转型预测：凡把捕获时点从"开发时"移到"持有/交易时"的改革，都会把城市边际生长从横向拨向纵向，并使存量维护的财政回报首次为正（"老城从包袱变回税源"）。阵痛不在经济逻辑而在征管与政治——Oates 收益观与 Tiebout 竞争的实践考场。

中国实践 BOX 6.2｜城市更新"资金自平衡"：存量财政的微观预演
更新单元"拆建比、资金自平衡"= 在存量子集上复制一次性变现逻辑（卖增容面积覆盖拆迁成本）。评价：①仍是"卖面积"而非"养税基"；②增容指标有全市影子价格——单单元平衡 ≠ 全市最优密度（此单元增容摊薄彼单元价值）；③正确核算需要第 7 讲的城市内 QSE——下一讲最现实的应用题。

两讲小结

  1. 资本化率由供给弹性与迁移摩擦决定——是供给体制的显影而非 Tiebout 检验；识别四代演进，识别越严效应越小；归宿普遍归于存量房主；增值捕获工具谱系决定融资—受益匹配与政府激励；
  2. AMM 三重边界联立决定形态；土地财政机制链（一次性预收 → 增量偏好 → 双轨出让 → 蔓延 + 配给 + 割裂）；挤压效应警示单点改革的替代扭曲；存量转型的形态预测是"横向转纵向、存量变税源"；
  3. 两讲合起来给出城市内空间财政学的完整闭环：资本化（价格信号）→ 形态（数量反应）→ 均衡核算（第 7 讲 QSE）。

  1. 推导式 (5.1) 资本化率对供给弹性的比较静态；讨论"限购+限售"如何同时移动供需弹性；

  3. 多校划片后优质学区 −8%、薄弱 +5%：完整归宿核算与效率—公平评价；
  4. 推导 AMM 中"通勤成本降 20%"在横向/纵向间的分流；若纵向弹性为零，房价承担全部调整；

  6. 【数据练习】本市多校划片试点的事件研究 DID（含租金通道）；或 2005–2023 地级市土地财政—扩张门限回归 + 增长预期遗漏变量的稳健性。
