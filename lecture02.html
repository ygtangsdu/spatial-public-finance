SPATIAL PUBLIC FINANCE · 第 2 讲（共 14 讲）

理论基础：NEG、财政联邦主义与空间均衡的融合

核心—边缘模型 · Tiebout–Oates–ZM 定理 · 策略性地方政府的空间均衡 · 中国式联邦主义辩论

本章导读

本讲完成理论基础的三个任务：其一，正式展开 Krugman（1991）核心—边缘模型——推导其三个核心方程，理解"循环累积因果"何时占优、何时被拥挤力遏制；其二，系统化财政联邦主义的规范基准——Tiebout 效率条件、Oates 分权定理、财产税归宿三观点之争、Zodrow–Mieszkowski 逐底竞争模型；其三，展示融合的前沿形态——当地方政府作为策略参与者进入空间均衡时，经典结论如何被改写。本讲以中国式联邦主义辩论收尾，将理论落到中国的制度土壤。

学习目标

  2. 推导并解释 Oates 分权定理的权衡结构与 Tiebout 均衡的效率/失败条件；
  3. 比较财产税归宿三种观点及其对"房产税开征"的不同预测；
  4. 运用 ZM 模型解释逐底竞争机制与矫正思路；
  5. 评价"财政分权促进增长"的中国证据及其识别困难；
  6. 构建把地方政府行为写入空间均衡的简化融合框架，为第 4 讲量化版本做准备。

2.1 核心部分：Krugman（1991）核心—边缘模型

2.1.1 模型环境

两区域、两部门：制造业 M（Dixit–Stiglitz 垄断竞争，替代弹性 σ，冰山贸易成本 τ）与农业 A（完全竞争、无贸易成本、计价物）。农业劳动不可流动且均匀分布；制造业劳动可跨区流动，按实际工资差迁移。上层偏好 Cobb–Douglas：制造业支出份额 μ。关键参数组合：

（2.1）　ρ = μ(σ−1)/σ（"关联度"参数：制造业份额高、产品差异化高 → 集聚力强）

2.1.2 三个核心方程

（a）工资方程——由垄断竞争定价与零利润条件，区域 r 的工资由"支出加权的市场可达性"决定：

（2.2）　wr = [ Σs (Ys / Psσ−1) · Grs−σ ]1/σ · 常数

靠近大市场可付更高工资（本地销售省贸易成本）——市场规模效应的正式表达。

（b）价格指数方程：

（2.3）　Pr = [ Σs (ns ps Gsr)1−σ ]1/(1−σ)

企业越集中的区域物价指数越低——价格指数效应。

（c）迁移方程：制造业劳动向实际工资 ωr = wr/Prμ 高的区域流动。（2.2）（2.3）相互作用产生核心机制：工人迁移 = 支出迁移 = 市场规模变化 = 工资变化 = 进一步迁移——循环累积因果。制动力是农业不可流动劳动与（量化版本补上的）住房拥挤成本。

2.1.3 均衡结构：对称破裂与"钉状图"

对称均衡（λ = 1/2）在贸易成本高或极低时稳定；在中间区间失稳，经济跳向核心—边缘结构。政策含义：同一政策在不同参数区间可能产生方向相反的空间后果——基础设施改善（τ 下降）在分散力仍强时保护边缘区产业份额；越过临界点后反而触发向核心的骤然集中。这是第 10、11 讲区域政策评估的结构直觉。

方法角 BOX 2.1｜从"钉状图"到 exact hat algebra：NEG 的两次定量化
第一次是"可估计的 NEG"：用引力方程把（2.2）的市场可达性变成可回归对象，ρ、σ 可由贸易数据估计。第二次是 Dekle–Eaton–Kortum（2008）式"帽子代数"：只求解政策冲击后的相对变化（ŵ, P̂），把反事实从"校准模拟"变为"半参数估计"（第 4 讲展开）。核心—边缘模型的三个方程是全部量化空间模型的祖先。

2.1.4 NEG 的财政空白与补白

标准 NEG 没有政府，但立即引出财政问题：谁向核心区的集聚租金征税？集聚租金意味着核心区政府可以在不引发产业外逃的情况下征收正的税收（"core 可以征税而不失位"）；边缘区则面临"减税也拉不回产业"的困境。税收竞争呈现中心—边缘非对称：竞争压力集中于"边缘对边缘"。这是理解中国"开发区竞争为何长期存在于同类城市之间"的钥匙（第 8 讲）。

2.2 联邦主义核心部分

2.2.1 Tiebout（1956）：效率条件与失败条件

强假设：完全流动、辖区类型连续、信息完全、居住与就业无关、辖区规模最优、无外溢。均衡实现按偏好分类（sorting）、辖区内部偏好同质、公共品供给满足 Samuelson 条件。失败条件同样重要：迁移成本 → sorting 不完全；技能差异 + 财政动机 → 辖区"择优而栖"（zoning，Hamilton 1976）；外溢与规模经济打破最优规模。实证难题：资本化、辖区分化等含义并非 Tiebout 独有预测（竞争性开发商模型亦然）；Rhode–Strumpf（2003）用美国百年数据未发现 sorting 随迁移成本下降而强化的证据——Tiebout 是有用的基准而非现实描述。

2.2.2 Oates（1972）分权定理：规范基准

若公共品供给无成本差异、无外溢，则只要辖区间偏好存在差异，分散供给弱优于集中供给。结构表达：损失函数为偏好偏离的凸函数时，地方按本地偏好 θi 供给的期望损失恒小于中央按 θ̄ 统一供给——分权收益随偏好异质性 Var(θ) 上升、随外溢与规模经济代价上升而下降。"异质性—外溢权衡"是所有政府间财政设计的骨架：都市圈跨界服务（第 9 讲）是"外溢 > 辖界"的直接应用；中国纵向失衡（第 8 讲）可读作定理的扭曲版本。

2.2.3 财产税归宿：三种观点

观点归宿机制中国对应物
传统观点住房消费者（累退）财产税作为对住房消费的货物税转嫁"房产税推高租金"论
新观点（Mieszkowski 1972; ZM 1986）全国资本所有者（累进）+ 地域错配全国视角下是对全域资本的差别化征税；税率差异引发资本跨区错配城市间税率自主的错配风险
收益观点（Oates 1969; Hamilton 1976）中性（使用者付费）Tiebout 竞争 + zoning 使税负完全内部化"健全地方税体系"论（税—服务对应）

分歧本质是对 Tiebout 竞争完善程度的判断。第 6、7 讲把这一争论放进中国城市内结构估计。

2.2.4 Zodrow–Mieszkowski（1986）：逐底竞争基准模型

环境：N 个同质辖区，资本全国固定供给，辖区对本地资本征税提供公共品，纳什互动。机制：单辖区提税 → 本地资本净收益率降 → 资本外流 → 本地工资下降；辖区决策忽略对他区的正外部性 → 纳什均衡税率低于社会最优、公共品供给不足。三个扩展：①集聚修正（核心区可征集聚租金税，竞争非对称，第 8 讲）；②标尺竞争（竞争经由选举问责传导，Besley–Case 1995）；③中国形态（税收返还 + 土地补贴 + 基建配套的捆绑竞争，第 8 讲）。

概念辨析 BOX 2.2｜"逐底竞争"效率判断的三个易混口径
① 对流动资本征税的竞争无效率（ZM 原型）；② 受益税（对不可流动居民按受益征税）下竞争中性；③ 若地方政府行为本身扭曲（过度投资、重复建设），竞争可能约束政府。判断"竞争好坏"必须先问：竞争的工具是什么、税基流动性如何。三口径在第 8 讲评估中国税收竞争时都会用到。

2.3 融合：策略性地方政府的空间均衡

2.3.1 三个不可回避的反馈环

环传导链忽略它的后果
A 资本化环税率/服务 → 迁移与房价 → 税基与土地价值 → 预算 → 税率/服务高估一次性减税的持续流入；误读房价上涨
B 集聚环政策 → 市场可达性 → 企业区位 → 就业工资 → 人口支出 → 可达性把边际效应外推到临界点之外（门槛效应）
C 竞争环本辖区政策 → 他辖区税基/反应 → 本辖区均衡单辖区"最优"在均衡中自我抵消

最小融合框架（为第 4 讲准备）：

（2.5）　maxti, gi Wi = V(ti, gi; wi, Pi)　s.t.　ti·Bi(w, P) + 转移支付 = gi·Ni + 基建成本

其中 (wi, Pi) 由空间均衡内生决定，Bi(·) 是资本化后的税基函数——把"地方政府是均衡参与者"形式化。

2.3.2 融合改写的三个经典结论

结论一：分权效率与集聚效率可能冲突。递增收益下"按本地偏好分散供给"可能锁定低集聚均衡；都市圈治理（第 9 讲）本质是重划"异质性—外溢—集聚"边界。

结论二：资本化的福利含义取决于住房供给与迁移摩擦。无摩擦时是中性信号；有摩擦时把服务差异转嫁为财富再分配（先入者获益、后来者付高价）——学区房溢价的分配后果（第 5 讲）由此而来。

结论三：税收竞争的均衡结构由空间结构决定。对称辖区 → 对称低税均衡；核心—边缘 → 核心可征税、边缘"减税无效"。比"逐底"更精确的语言（第 8 讲）。

方法角 BOX 2.3｜结构模型中的"政府"：从幽灵到演员
第一代量化空间模型中政府是幽灵——只出现在反事实里。前沿工作让政府成为演员：Fajgelbaum 等让州政府设定州税、居民企业跨州流动，估计税收空间错配；城市内版本让地方政府选择土地供给或分区强度。让政府内生化是空间财政学方法论的核心议程，也是期末论文最有潜力做出增量的问题域（第 14 讲）。

2.4 中国语境：市场维护型联邦主义及其批评

2.4.1 假说：Federalism, Chinese Style

Jin–Qian–Weingast（2005）：1980 年代财政承包制形成"市场维护型联邦主义"——①包干契约使地方对边际财政收入有强索取权；②辖区间竞争约束政府攫取；③中央维持分权规则。证据：省级边际留成率与省属企业效率、非国有化进程正相关。MPF 把 Tiebout/ZM 逻辑移植到"地方政府对企业的竞争"。

2.4.2 批评与修正

Zhang 等（2006）：中国是"财政分权 + 政治集中"，分权效果依赖中央考核任命而非"可信承诺"；激励是"对上负责"与"增长锦标赛"混合。周黎安（2007）晋升锦标赛：晋升基于相对增长考核——解释增长动力，也解释重复建设、地方保护与"重基建、轻民生"（基建进入考核，民生不进入）。分税制转折（1994）：收入集中化削弱剩余索取权，地方转向"土地财政 + 预算外融资"重建边际激励——理论焦点从"承包激励"转向"土地财政激励"（第 6 讲）。

中国实践 BOX 2.4｜用三环框架读"开发区竞争"
环 A：开发区"三免两减半 + 低价土地"改变企业落户的资本化计算——土地低价是政府让渡的负资本化；环 B：企业落户改变市场可达性，触发上下游集聚（Lu–Wang–Zhu 2019 的创造效应与拾取效应并存，第 3 讲精读）；环 C：邻近城市竞相设区，边际租金被竞争耗散。三环合起来预测：开发区数量的竞争均衡超过社会最优（重复建设），但对每家入驻企业补贴可能仍不足以覆盖其集聚外部性——两种低效并存，第 10 讲结构评估要拆开的账。

2.4.3 从理论到识别：因果难题与出路

"财政分权 → 增长/服务"的回归受困于分权内生性。可信出路：①分税制、省直管县等制度断裂做 DID（第 3 讲工具）；②承包契约谈判细节构造边际留成率外生变异；③把"分权效应"分解为收入端激励、支出端责任、考核权重三个可分别识别的参数。这是课程论文的方法接口。

本章小结

  1. 核心—边缘模型三方程刻画循环累积因果；对称破裂与门槛效应是空间政策评估必须内生的均衡现象；
  2. Tiebout 效率条件与失败条件同样极端；资本化与 sorting 是可检验含义但非独有预测；
  3. Oates"异质性—外溢—规模经济"权衡是政府间财政设计骨架；财产税三观点分歧在于对 Tiebout 竞争完善程度的判断；ZM 给出逐底竞争基准；
  4. 融合框架下地方财政嵌入资本化环、集聚环、竞争环；分权效率与集聚效率可能冲突、资本化福利取决于摩擦、税收竞争结构由空间结构决定；
  5. 中国式联邦主义辩论说明财政激励必须与政治激励联合识别；分税制后激励载体从财政承包转向土地财政。

思考与练习

  1. 用（2.2）（2.3）的直觉解释：为何交通改善（τ 下降）在边缘区产业份额较高时可能保护边缘区、越过临界点后反而加速边缘化？对中西部高铁投资评估意味着什么？
  2. 推导：若公共品外溢比例为 θ，Oates 分权收益条件如何改写？用它讨论"跨市地铁应由谁出资"；
  3. 财产税三观点对"开征房产税推高还是压低房价"各有何预测？写出假设链并标注哪条在中国情境下最可能失效；
  4. 现实地方税率长期稳定且差异巨大，与 ZM 预测不符。给出三种理论解释（集聚租金/标尺竞争/投票而非税基流动），各配一个可检验含义；
  5. 【辩论题】正方"财政承包制是增长引擎" vs 反方"分税制才是市场统一功臣"，各准备论点与证据三条；
  6. 【建模练习】在（2.5）式中设定线性城市两辖区、住房供给弹性不同，写出房价对税率差的反应函数草图，说明供给弹性如何调节资本化环强度。
